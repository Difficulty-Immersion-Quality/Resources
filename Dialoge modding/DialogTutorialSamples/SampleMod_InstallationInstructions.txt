Sample mods were made for Patch 6, Hotfix 25!

Install loose file mods by dragging the "Public" folder in the "ForInstallation" folders into your BG3 Data folder!

Make sure you're not testing these mods with other mods that edit the same scenes, including my own mods, like Wyll's Act 3 Romance Tweaks, Astarion Romance Reactions Fixed,
and Suddenly Strong Astarion Begone.

To uninstall, just delete the loose files from your BG3 Data folder. All changes made by the mods should revert on uninstallation, even mid-playthrough.


To install the .pak sample mod:

The mod demonstrating TLSwitchLocationEvent/TLAtmosphereAndLighting needs to be installed as a .pak file, due to it using a custom SceneTrigger, which has to be packed.

Install via BG3 Mod Manager, and make sure the .pak is in your load order! The .pak mod should also be safe to uninstall, even mid playthrough.

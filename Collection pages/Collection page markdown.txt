# ✅Pre-Install: Having and Maintaining Clean Install - Step #1

2. [Auto-Clean-Cache Script for Baldur's Gate 3](https://www.nexusmods.com/baldursgate3/mods/14495) is a script you can install so each time Windows starts up the game's `%LocalAppData%\Larian Studios\Baldur's Gate 3\LevelCache`, and other temp files are cleared. This is highly beneficial for avoiding issues that may arise over time were it otherwise not cleaned out.\
   \
   Alternatively, you can just run the executable file manually before playing the game, keep it on your desktop of wherever you want!\
   ![](https://staticdelivery.nexusmods.com/mods/3474/images/14495/14495-1735549500-1291419674.png)

<details><summary>💡Game: Setup - Step #2</summary>
# 💡Game: Setup - Step #2

1. In [Steam](https://store.steampowered.com/about/) go to ***Library*** and right click ***Baldur's Gate 3*** select ***Properties*** -> ***Updates*** -> ***Automatic Updates***  set it to ***Only update the game when I launch it***.\
   \
   **Note:** There's a good reason for this, you don't want to update the game prior to collection revisions coming out, if there's an update available without a matching collection revision set [Steam](https://store.steampowered.com/about/) into ***Offline Mode*** prior to launching.\
   For more information please read ***2: Updating Guide - Collection & Game Updates***⚠️.\
   ![](https://i.postimg.cc/zGWhHZQP/image2222222222222222222222222222.png)
2. In [Steam](https://store.steampowered.com/about/) go to ***Library*** and right click ***Baldur's Gate 3*** select ***Properties*** -> ***Installed Files*** select ***Verify integrity of game files***.\
   You'll need to wait for this process under your [Steam](https://store.steampowered.com/about/) downloads to finish before continuing.\
   **Note:** I've even seen fresh installs get fixed from doing this, you are not above this step!\
   **ALSO:** If you're playing on a downgraded install you cannot ***Verify integrity of game files*** without [Steam](https://store.steampowered.com/about/) fetching files from the latest version, so in these cases skip this step. For more information please read ***2: Updating Guide - Collection & Game Updates***⚠️. \
   ![](https://i.postimg.cc/gkjqJ7df/image11111111111111111111.png)
3. Once your install is finished being verified by [Steam](https://store.steampowered.com/about/) launch the game to open the ***Larian Launcher*** and select the ***Settings*** cog icon, underneath ***General*** untick the box for ***Enable stats tracking***.![](https://i.postimg.cc/MpFWwv5C/image.png)![](https://i.postimg.cc/cChSbH65/image.png)
4. Again in the ***Larian launcher***, use ***DirectX 11*** instead of ***Vulkan*** as your game's API.\
   This is a general recommendation for performance and mod functionality, I've seen very few users have a better time with ***Vulkan***.\
   ![](https://i.postimg.cc/VLNQNzJm/image.png)
5. New with **Patch #7** is making sure you're not signed in to **ANY** in game accounts! If you're signed in to accounts the game will subscribe you to collection mods that are also present on [mod.io](https://mod.io/g/baldursgate3). This can cause dirty installs, especially when updating DIQ.\
   \
   You can unsubscribe from mods in game if you're signed into [mod.io](https://mod.io/g/baldursgate3), alternatively, unsubscribe from mods on the [mod.io](https://mod.io/g/baldursgate3) website.\
   **Note:** [mod.io](https://mod.io/g/baldursgate3) and [Larian](https://larian.com) accounts are separate but can be linked.\
   \
   If using the [mod.io](https://mod.io/g/baldursgate3) website just filter by ***My subscriptions***, then click the ***Subscribed*** button to unsubscribe from each mod. This helps to ensure your game won't download a bunch of conflicting mods.\
   ![](https://i.postimg.cc/kXVP4Tfk/Screenshot-2024-11-28-151349.png)
6. Launch into the game at least once on a clean game install to generate files. This includes going through character creation and into the tutorial level to make sure it's working as intended.
7. Under ***Video*** -> ***General*** set ***Display Mode*** to ***Fullscreen***.\
   Unless you're constantly tabbing out of the game It's generally better for performance and stability, if you tab out a lot however it could lead to the opposite, causing infrequent crashing or lead to noticeable performance loss over the course of a long play session.![](https://i.postimg.cc/FFBGjvP9/image.png)
8. Under ***Video*** -> ***Quality*** set ***Animation Level of Detail*** to ***High***, otherwise custom heads and hair will have graphical issues.![](https://i.postimg.cc/HnxZTsBN/image.png)
9. For future convenience, in [Steam](https://store.steampowered.com/about/) go to ***Library*** and right click ***Baldur's Gate 3*** select ***Properties*** > ***General*** > ***Launch Options*** type ***--skip-launcher***.![](https://i.postimg.cc/G23zjmwp/image33333333333333333333333333333333333.png)
10. Proceed to the next drop down menu: 💡***Vortex: Setup - Step #3***.
</details>

<details><summary>💡Vortex: Setup - Step #3</summary>
# 💡Vortex: Setup - Step #3

1. Download and install [Vortex](https://www.nexusmods.com/about/vortex/). In the ***Games*** tab, select ***Manage*** on Baldur's Gate 3. The installed path should be recognised automatically, if not point [Vortex](https://www.nexusmods.com/about/vortex/) it to the game's install.![](https://i.postimg.cc/nL1GD6zZ/image.png)
2. **WARNING:** DO NOT install [LSLib/Divine Tool](https://github.com/Norbyte/lslib) when prompted by [Vortex](https://www.nexusmods.com/about/vortex/), ***Uninstall*** it if need be do not just ***Disable*** it.\
   This tool is needed by [Vortex](https://www.nexusmods.com/about/vortex/) to touch the load order, we do not want [Vortex](https://www.nexusmods.com/about/vortex/) touching the load order. [Vortex](https://www.nexusmods.com/about/vortex/) runs much faster without it.\
   If you needed to uninstall the [LSLib/Divine Tool](https://github.com/Norbyte/lslib) please restart [Vortex](https://www.nexusmods.com/about/vortex/) before continuing with the installation.![](https://i.postimg.cc/0ydpH1CK/image.png)
3. **NOTE:** The location of these is very important, putting them inside any of the game's folders will cause serious issues.\
   In [Vortex](https://www.nexusmods.com/about/vortex/) under ***Settings*** -> ***Download*** set the ***Downloads Folder*** outside of the game files. Default path is fine, below is where I have mine located.![](https://i.postimg.cc/SxgKYdh3/image.png)
4. In [Vortex](https://www.nexusmods.com/about/vortex/) under ***Settings*** -> ***Mods*** set the ***Mod Staging Folder*** outside of the game files. Default path is fine, below is where I have mine located.![](https://i.postimg.cc/4dLnC18p/image.png)
5. In [Vortex](https://www.nexusmods.com/about/vortex/) under ***Settings*** -> ***Mods*** set ***Deployment Method*** to ***Symlink Deployment***. \
   ***Hardlink Deployment*** is the default, however ***Symlink Deployment*** is used when the Vortex staging folder is on a different storage device to the game's folders (including both the appdata folder and the game install). ***Symlink Deployment*** will also save you storage space, and is what I choose to use.\
   \
   **WARNING:** Always ***Purge*** mods in [Vortex](https://www.nexusmods.com/about/vortex/) prior to changing ***Deployment Methods***. Otherwise mods already deployed to the game's folders could fail to be managed by [Vortex](https://www.nexusmods.com/about/vortex/), and you will have to remove them manually just as you may have done towards the beginning of this guide.![](https://i.postimg.cc/sXZbyjmK/image.png)
6. In [Vortex](https://www.nexusmods.com/about/vortex/) under ***Settings*** -> ***Mods*** disable ***Auto export load order***.![](https://i.postimg.cc/brhNbFF0/image.png)
7. In [Vortex](https://www.nexusmods.com/about/vortex/) under ***Settings*** -> ***Workarounds*** enable ***Allow Symlinks without elevation***.![](https://i.postimg.cc/G28n2JLF/image.png)
8. In [Vortex](https://www.nexusmods.com/about/vortex/) under ***Settings*** -> ***Interface*** -> ***Automation*** -> disable ***Run Vortex when my computer starts*** and ***Deploy Mods when Enabled***.![](https://i.postimg.cc/wTbYYGcW/image.png)
9. **Restart your PC for changes to take affect.**![](https://i.postimg.cc/3JWJGptc/image.png)
10. **REMINDER:** If you uninstalled the [LSLib/Divine Tool](https://github.com/Norbyte/lslib) please restart [Vortex](https://www.nexusmods.com/about/vortex/) before continuing with the installation.\
    You will get prompted to install it every time you open [Vortex](https://www.nexusmods.com/about/vortex/), just don't get tricked into installing it.![](https://i.postimg.cc/DyqFLgq5/image.png)
11. Proceed to the next drop down menu: 📥***Vortex: Download & Installation - Step #4***.

# 📥Vortex: Download & Installation - Step #4

1. Click the orange ***Add collection*** button at the top of this page to begin the collection download. If you have [Nexus Premium](https://next.nexusmods.com/premium) it will begin downloading all of the mods, if not you will have to click through the download prompts for each mod.![](https://i.postimg.cc/3JwyMVC7/Screenshot-2024-10-27-150805.png)
2. If you get stuck at 100% install/download, mods are missing, or anything weird happens remove the collection (but do not remove the mods, specifically the mod archives) and select ***Add collection*** again. Sometimes downloading hundreds of mods at the push of a button doesn't work right through [Vortex](https://www.nexusmods.com/about/vortex/), who could have guessed?\
   View ***3: Troubleshooting Guides*** for more information.![](https://i.postimg.cc/4ykzRZXx/image-2024-06-02-221319767.png)
3. Read over ***5: Optional & Archived Mods*** for information on each optional mod prior installing them, they're optional for a multitude of reasons. You've been warned.\
   ![](https://i.postimg.cc/Nf7gpQPk/image-2024-06-19-034858631.png)\
   This step ensures you won't have question such as: "Why does my Tav have different tattoos?" and "How can I remove this chat box?"\
   \
   When downloading optional mods you can hold the CTRL key and left click mods you wish to install, before installing them from the bar at the bottom of your screen. This saves time as [Vortex](https://www.nexusmods.com/about/vortex/) will automatically ***Deploy*** whenever an optional mod is installed. \
   **Note:** ***Deployment*** means the mods are being sent to the game files.\
   ![](https://i.postimg.cc/B6z3J72c/Screenshot-2023-11-25-082156.png)
4. Both in the next step and in the future whenever you're making more changes in [Vortex](https://www.nexusmods.com/about/vortex/) (updating etc.), verifying integrity of game files through [Steam](https://store.steampowered.com/about/), or cleaning out your game folders **ALWAYS** ***Purge*** mods prior!\
   **Note:** ***Purging*** removes mods from the game files, it doesn't delete them permanently or harm your install. It increases the efficiency of [Vortex](https://www.nexusmods.com/about/vortex/), and reduces the potential for issues to occur.![](https://i.postimg.cc/B6z3J72c/Screenshot-2023-11-25-082156.png)
5. It's at this point you may also wish to install [DIQ Extras](https://next.nexusmods.com/baldursgate3/collections/k3zucg) (more character customisation) and/or [DIQ Expanded](https://next.nexusmods.com/baldursgate3/collections/y0iw7z) (more build options), and/or [DIQ Armoury](https://next.nexusmods.com/baldursgate3/collections/y7cdjf) (more items) alongside [Difficulty, Immersion, Quality](https://next.nexusmods.com/baldursgate3/collections/pns4qv). Just like the previous step explains you should **Purge** mods prior to adding these addon collections.\
   These addon collections can be added at a later date if you just want to try the base collection first.\
   \
   **Note:** The addon collections must be installed into the same ***profile*** in [Vortex](https://www.nexusmods.com/about/vortex/).\
   \
   [DIQ Horny](https://next.nexusmods.com/baldursgate3/collections/1uysmm) is an exception, this 18+ addon has special instructions when it comes to the load order, because I just don't care for having those mods enabled in my game even while testing.\
   ![](https://i.postimg.cc/xTtmMZ9k/Untitled-design.png)
6. Toggle the column for ***Collection*** on your [Vortex](https://www.nexusmods.com/about/vortex/) ***Mods*** page, by clicking the cog icon in the top right. Click the ***Group*** icon for Collection as it will be mandatory for removing old mod files when updating the collection in the future.\
   Also toggle the column for ***Mod Type*** just for easier access to some of the more important mods, such as [Script Extender](https://github.com/Norbyte/bg3se), [WASD Character Movement](https://www.nexusmods.com/baldursgate3/mods/781), [Native Camera Tweaks](https://www.nexusmods.com/baldursgate3/mods/945) and [Native Mod Loader](https://www.nexusmods.com/baldursgate3/mods/944).\
   ![](https://i.postimg.cc/rmF30Gqn/Screenshot-2024-02-29-115337.png)
7. Make sure to ***Deploy*** mods before moving on from [Vortex](https://www.nexusmods.com/about/vortex/).\
   ![](https://i.postimg.cc/B6z3J72c/Screenshot-2023-11-25-082156.png)
8. Once all of the above looks good, you are ready to begin managing the load order with [BG3 Mod Manager](https://github.com/LaughingLeader/BG3ModManager/releases) ([BG3MM](https://github.com/LaughingLeader/BG3ModManager)). Do not even attempt to use [Vortex](https://www.nexusmods.com/about/vortex/) for handling the load order.
9. Proceed to the next drop down menu: 💾***Manual Installation: Configuration Files - Step #5***.

<details><summary>💡Collection Updates - Step by Step</summary>
# 💡Collection Updates - Step by Step

1. Prior to updating It is recommended that you do the following to maintain the health of an ongoing save:\
   \
   1\. Deactivate **ALL** toggle passives on your hotbars, and use the ***Remove Automation Toggles*** as shown in the GIF below.\
   **Note:** ***Remove Automation Toggles*** is now inside the ***Utility Spells*** spell container, AKA the big red exclamation mark.\
   .\
   2\. Respec characters to level 1 Barbarians, unless the character is already a Barbarian in which case you should select Fighter; you will have to redo your builds after successfully updating.\
   **Note:** This includes companions, hirelings, Tavs and Durges, both actively in the party and at camp.\
   .\
   3\. Long rest to remove other temporary statuses and just for the sake of ruling weirdness out.\
   \
   Failure to do so can result in issues for that save moving forward, though, usually the same process as above can be followed retroactively if issues arise, so long as the said issue isn't a save failing to load.\
   ![](https://i.postimg.cc/FsnDMTJf/Untitled-1000-x-250-px.gif)
2. Read the [changelog](https://next.nexusmods.com/baldursgate3/collections/pns4qv?tab=changelog), not just the most recent; but all changelogs from the revision you are currently on, up to the most recent.\
   \
   Follow any specific instructions found on the [changelogs](https://next.nexusmods.com/baldursgate3/collections/pns4qv?tab=changelog). This may consist of things such as: Respeccing character classes, unequipping or deleting items and uninstalling a mod through [Mod Uninstaller](https://www.nexusmods.com/baldursgate3/mods/9701).\
   \
   [Mod Uninstaller](https://www.nexusmods.com/baldursgate3/mods/9701) allows you to remove mods via the [Mod Configuration Menu (MCM)](https://www.nexusmods.com/baldursgate3/mods/9162) interface, making it easier to cleanly uninstall mods that add items, passives, statuses etc.\
   \
   **Using **[**Mod Uninstaller**](https://www.nexusmods.com/baldursgate3/mods/9701)**:**\
   1\. Open the [Mod Configuration Menu (MCM)](https://www.nexusmods.com/baldursgate3/mods/9162) in game while loaded into the save you wish to continue playing on\
   2\. Select the [Mod Uninstaller](https://www.nexusmods.com/baldursgate3/mods/9701) tab and wait for data to be analyzed\
   3\. Select the mod(s) you want to uninstall, click ***uninstall***.\
   4\. Save your game and exit, the mods are now ready to be safely removed outside of the game.\
   \
   *Example of using* [*Mod Uninstaller*](https://www.nexusmods.com/baldursgate3/mods/9701): (The interface looks a bit different nowadays)\
   ![](https://i.imgur.com/ZWL1YkP.gif)
3. ***Purge*** mods in [Vortex](https://www.nexusmods.com/about/vortex/). Select ***Update*** on the collection through the [Vortex](https://www.nexusmods.com/about/vortex/) ***Collections*** tab.![](https://i.postimg.cc/WzPVHWr9/Screenshot-2024-02-02-033034.png)
4. When prompted with ***Remove mods from old revision?*** select ***Remove All***.\
   ![](https://i.postimg.cc/nLKGDhtp/Screenshot-2024-02-02-033301.png)
5. Additionally you will be prompted to install the update into a new ***Profile***. I do not recommend this if you've customised the collection in any way, it will create more work for you. It's completely optional, and can be skipped assuming all other instructions are followed.\
   The primary benefit is the ability to swap between the ***Revision*** you've updated to, and the ***Revision*** you were on via ***Profiles***; helpful if you run into any issues, e.g.: you didn't respec a character using an updated class mod.\
   **NOTE:** Always put your addon collections into the same profile as the main collection, just like original installation.\
   ![](https://i.postimg.cc/Px1YTkYP/image-11.webp)
6. If you're prompted with external changes it's likely because you didn't ***Purge*** mods prior to updating, and [Vortex](https://www.nexusmods.com/about/vortex/) has just removed many mod files.\
   You can go ahead and save these changes, ***Deploying*** mods after the update will restore any loose files in use by the new collection revision.\
   If you get this prompt under different circumstances I'd recommend selecting ***Revert change (restore file)***. E.g.: You just verified the integrity of your game files through[ Steam](https://store.steampowered.com/about/) without ***Purging*** mods prior.\
   ![](https://i.postimg.cc/pLvvZ6xy/Screenshot-2024-03-08-183724.png)![](https://i.postimg.cc/hGKYzFnb/Screenshot-2024-03-08-184000.png)

In certain cases when updating it will not grab the new file for an optional mod, it will just delete it. This is due to file changes in the mod and [Vortex](https://www.nexusmods.com/about/vortex/) not understanding that it's a new iteration of the same mod.\
   .
9. If optional mods included in the current revision which you were using have been ***Uninstalled*** or ***Disabled***, please ***Install*** or ***Enable*** them. This just happens on occasion, it's hit or miss. Read [changelogs](https://next.nexusmods.com/baldursgate3/collections/pns4qv?tab=changelog) so you're aware of what has actually been removed, many optional mods are not safe to remove mid-playthrough.\
   .
10. You'll have mods grouped by ***Collection*** on your [Vortex](https://www.nexusmods.com/about/vortex/) ***Mods*** page, assuming you followed installation instructions shown again just below.\
    ![](https://i.postimg.cc/rmF30Gqn/Screenshot-2024-02-29-115337.png)Remove leftover mod files from the group titled ***Unspecified***.\

    ![](https://i.postimg.cc/5yyybnmD/imageeeeeeeeeeeeeee.png)
11. Under the ***Version*** column you will see some mods in the collection displaying that they have additional archives (orange boxes), these can be deleted too. These are just leftovers from updating mod files.\
    Click on it to display the drop down, the version at the top is currently installed. Select the ***minus -*** icon for the version below to remove them. Toggle the little box in the bottom right to delete archives.\
    ![](https://i.postimg.cc/DzVXBF0L/Screenshot-2024-03-05-082217.png)If you're using some of the optional mods the ***Some mods are redundant warning*** will be present and not a problem, otherwise both of these warnings will go away once leftover mod files are all removed.\
    ![](https://i.postimg.cc/R0XvqQkh/Screenshot-2024-02-02-032627.png)Once you've cleaned things out properly ***Deploy*** mods in [Vortex](https://www.nexusmods.com/about/vortex/).\
    .
12. Extract new configuration files if they've been updated.\
    If you need a refresher on the configuration files please view ***1: Installation Guide - Vortex, BG3MM & Configs***💡->💾***Manual Installation: Configuration Files - Step #5***.\
    .
13. Export the new load order to the game through [BG3MM](https://github.com/LaughingLeader/BG3ModManager).\
    If you need a refresher on the load order please view ***1: Installation Guide - Vortex, BG3MM & Configs***💡 ->📋***BG3MM: Load Order Management - Step #6***.

- If [Steam](https://store.steampowered.com/about/) is not open, you don't use a [Steam](https://store.steampowered.com/about/) shortcut for the game executable, and you don't have ***Launch Through Steam*** enabled in [BG3MM](https://github.com/LaughingLeader/BG3ModManager), [Steam](https://store.steampowered.com/about/) will not open and no updates will be downloaded.
- If [Steam](https://store.steampowered.com/about/) is open it **HAS** to be in in ***Offline Mode*** prior to launching the game, in addition to ***Automatic Updates*** being set to ***Only update this game when I launch it*** per the setup instructions for this collection.
- ***Verifying integrity of game files*** will fetch files from the latest release, don't do it. If your install is cooked you'll have to use the [Steam Community :: Guide :: Rollback to a Previous Game Version](https://steamcommunity.com/sharedfiles/filedetails/?id=3023295121) guide to get previous patch/hotfix data.
- If your copy of BG3 is from [GOG](https://www.gog.com/galaxy) it's much easier to avoid updating. From the game's page in your [GOG Galaxy](https://www.gog.com/galaxy) library select ***Manage Installation*** then ***Configure...***, underneath ***Installation*** untick the box for ***Automatically update to newest version***.

## ⚡️Soft Rebooting Your Vortex Collection Install:

This is generally followed for resolving [Vortex](https://www.nexusmods.com/about/vortex/) issues such as missing ***Rules*** for loose file overwrites and such, but it can also help just clean up a messy Vortex environment.

1. ***Purge*** mods in [Vortex](https://www.nexusmods.com/about/vortex/).

# ⚡️Multiplayer Issues & Troubleshooting

Patch #7 was a bad time for multiplayer, and it seems that with Patch #8 improving Larian's mod validation and what not multiplayer has been improved also. If you're having trouble connecting to your friends, it's 100% not an inherent issue with the collection, or the mods included in the collection.

Some general information for successfully playing modded multiplayer:

- Direct connect is the best means of connecting, no Steam, no Larian account, no BS; it just works™.
- All mods in your active load order must match, only loose files can be different. E.g. Some of the optional texture mods.

# 🤬Difficulty: To Customise or Overcome?

[Combat Extender](https://www.nexusmods.com/baldursgate3/mods/5207) is the primary mod controlling the increased difficulty in this collection, for some users my [configuration file](https://www.nexusmods.com/baldursgate3/mods/9784) for [Combat Extender](https://www.nexusmods.com/baldursgate3/mods/5207) is too much.&#x20;

- I encourage everyone to customise this config to their liking, I highly recommend you use [Visual Studio Code](https://code.visualstudio.com) as it will let you know if you've made errors, or at least [Notepad ++](https://notepad-plus-plus.org) instead of [Notepad](https://apps.microsoft.com/detail/9msmlrh6lzf3?hl=en-US\&gl=US).
- [Configuration Explained](https://github.com/Zehtukae/combat-extender/blob/main/Source/ConfigurationExplained.json#L281) is an overview of how the config works.
- If your [Script Extender](https://github.com/Norbyte/bg3se) console is filling up with red texts usually referring to boosts not being applied then you've made errors.
- You can make edits to your ***CombatExtender.json*** in `%AppData%\Local\Larian Studios\Baldur's Gate 3\Larian Studios\Baldur's Gate 3\Script Extender` while the game is running, and load a save to apply changes. Great for testing!
- While you can just remove the mod (***Disable*** in [Vortex](https://www.nexusmods.com/about/vortex/), redo [BG3MM](https://github.com/LaughingLeader/BG3ModManager) steps) you will be missing out on some interesting gameplay changes, such as enemies using many more spells and abilities, keeping combat fresh and interesting.
- **Note:** [Combat Extender](https://www.nexusmods.com/baldursgate3/mods/5207) uses Tactician difficulty stats as a base, decreasing the difficulty from Tactician has no impact on the buffs provided to enemies through [Combat Extender](https://www.nexusmods.com/baldursgate3/mods/5207)'s configuration file.
- Just bellow is the related lined for health, the `StaticBoost` 0.150 means all NPCs of that type have their health increased by a flat 15%, and the `HealthPerLevel` of 0.100 is giving another 10% per level of the creature. Given that the Tactician difficulty (used as a baseline) increases it by 30%, the collection essentially doubles the health of all NPCs at the higher levels.
- **Note:** `Allies` does not apply to player characters.

```
  "Health": {
    "Allies": {
      "HealthMultiplier": 0,
      "StaticBoost": 0.150,
      "HealthPerLevel": 0.100
},
    "Bosses": {
      "HealthMultiplier": 0,
      "StaticBoost": 0.250,
      "HealthPerLevel": 0.150
},
    "Enemies": {
      "HealthMultiplier": 0,
      "StaticBoost": 0.150,
      "HealthPerLevel": 0.100
```

### Overcoming the challenges:

Below is some general advice for dealing with the increased difficulty.

- Use crowd control spells such as Command, Hold Person and Sleep, instead of focusing on strictly doing damage.
- Use Bless and other buff spells. Casters using Concentration spells should have Constitution Proficiency to succeed Saving Throws more often, you can get this from numerous sources, such as gear.
- Don't sleep on consumable items.
- Focus on positioning, positioning can be everything.
- Think about synergistic builds. I recommend 2 physical damage dealers and 2 casters for the average player, with your casters primarily providing utility, while you physical classes get to killing. (This is especially ideal in the early game, as casters begin to really come online with level 2 and 3 spells.)

# ❓Temporarily Reverting Your Game to a Vanilla State

"I want to return to a vanilla playthrough without deleting the collection, is it possible?"

You can easily return the game to a near-vanilla state temporarily by:

1. ***Purging*** mods in [Vortex](https://www.nexusmods.com/about/vortex/), or swapping to another empty ***profile*** in [Vortex](https://www.nexusmods.com/about/vortex/).&#x20;
2. ***Exporting*** an empty load order with [BG3MM](https://github.com/LaughingLeader/BG3ModManager), or, you can just delete the `modsettings.lsx` inside `%LocalAppData%\Larian Studios\Baldur's Gate 3\PlayerProfiles\Public\Savegames\Story`.

To reactivate your collection install just:

1. ***Deploy*** mods in [Vortex](https://www.nexusmods.com/about/vortex/), or swap to the DIQ [Vortex](https://www.nexusmods.com/about/vortex/) ***profile***.&#x20;
2. ***Export*** the appropriate load order with [BG3MM](https://github.com/LaughingLeader/BG3ModManager).

This is not the same as a clean install, and just for temporarily swapping to vanilla.

<details><summary>🧌Where's the Custom Race Mods?</summary>
# 🧌Where's the Custom Race Mods?

I currently have a few reasons for not being interested in custom races.

### **A lack of all in one patches for mods adding CC options:**

Many mods have proprietary patches for X, Y, Z race mods. This is a problem when it comes to bloat, more pak files means longer loading times, and having potentially dozens of individual pak files so a single custom race can have more options doesn't feel like good bang for my buck. Many authors are against AIO patching and only offer individual patches, so I'm unsure if this is a resolvable problem.

### **Unbalanced and overpowered racial stats:**

This speaks for itself really, vanilla races are reasonably well balanced, many custom races are not.

### **A lack of custom tags and dialogue:**

Walking around as an Angel, Bugbear or Goblin might be cool, but it's made a lot less cool when the world doesn't react to you as such.

### **Bugs:**

Some race mods have issues, most seem just fine but I've had quite a few users of DIQ come into the [Discord](https://discord.gg/baldursgoonsacks) with problems caused by a custom races they added. If you're intent on adding them make sure to read all available information, make sure it's not long since abandoned.

### **The inability to remove the mods:**

Over the course of curating DIQ I have rarely had a save with issues I could not fix for someone, unless they had a bugged out honour save with no backups (don't do that).\
\
Throughout my updates I always keep in mind users with ongoing playthroughs, were a custom race to be a pain point and need removing it would be a bit of a predicament. Custom items can now be rather easily removed through Mod Uninstaller. Class mods are usually not a problem at all to remove, it's just not the same if a custom race is in use. Resculpt could be used through Appearance Edit Enhanced, but that's a last resort. I don't really trust that feature, even though some of its most glaring issues only appear to come up when it's used on Origin characters.
</details>

- [Smart Autosaving](https://www.nexusmods.com/baldursgate3/mods/5899) \
  Smart Autosaving is a mod designed to autosave regularly while minimizing gameplay interruption.\
  \
  **Condition-based autosaving**: The mod autosaves at regular intervals (10 minutes by default), but it also checks various in-game states, like whether the player is in dialogue, trading, combat, lockpicking, etc. Based on these checks, it decides whether to trigger an autosave.\

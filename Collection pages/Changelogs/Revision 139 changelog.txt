- If [Absolute's Laboratory - NPC and Combat Inspector and Mutator](https://www.nexusmods.com/baldursgate3/mods/16217) isn't properly set up in Revision 140 @diimmortalis is allowed to snip my willie off.
- Fixed a shit load of bugs, including some long standing annoyance with passive boost stacking and stuff, thanks to @diimmortalis' [Passive Boost Deduplicator](https://www.nexusmods.com/baldursgate3/mods/19523).
- Revision 138 really wasn't as crispy as intended, and the turnaround for getting a hotfix revision out was weeks past what I wanted. So that's how we ended up with a decent list in the 🪲**Known Issues + Workarounds** [pinned comment](https://www.nexusmods.com/games/baldursgate3/collections/pns4qv/comments?commentId=172148), but this revision really shouldn't have any surprises. Since Revision 136 development of DIQ has been rather reactive to bugs and all that, but moving forward I should be able to largely focus on polish and features, getting to the intended point that I was never really able to reach months ago. If all goes well I hope to be "finished" with developing DIQ in 6 months or so, putting the list into maintenance mode and potentially adopting a new main project if I feel it's worth the time.
- A number of mods now have dependencies set up in [Vortex](https://www.nexusmods.com/about/vortex/). This will assist people with installing optional mods that other optional mods as dependencies, and make the list a lot more customisable for the average user; as disabling a mod may provide a warning if it's a dependency for another mod. This is not universally implemented, it's just some notable ones for now. \
  ❗️**Update:** Apparently these dependencies did not come through with the collection update.
- [Companion And NPC Face Texture Tweaks](https://www.nexusmods.com/baldursgate3/mods/36) broke for some reason, probably related to my new OS and transferring of files; I'll look at having a properly clean [Vortex](https://www.nexusmods.com/about/vortex/) environment for Revision 140; I tried troubleshooting it but it's simply not included for 139. If you want to add it (loose files version), delete the Human folder from `Generated\Public\Shared\Assets\Characters\_Models` in its staging folder, and set it to load BEFORE all the conflicts in the [Vortex](https://www.nexusmods.com/about/vortex/) rules.

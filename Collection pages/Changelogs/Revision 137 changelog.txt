***

- Load order fixes for [Sailor](https://www.nexusmods.com/baldursgate3/users/78518828)'s mods, and related mods
- A bajillion bug fixes within my own mods, and some others, namely crashes related to status application via auras, free cast spells in spell upcasting containers
- [Armory](https://www.nexusmods.com/baldursgate3/mods/14717) transmogging now works out of the box without need to update mods
- Removed [Combat Extender](https://www.nexusmods.com/baldursgate3/mods/5207) clones, because taking their corpses to another level caused issues
- Body tattoo issues are all fixed up, but only the default atlas is included\
  **Note:** Keep in mind that body tattoo selection via character creation is a single channel, and body tattoos can have 3 channels. Not all atlases you add will be created with this limitation in mind, for the exceptions you ought to use the new addition [Character Appearance Editor (Charactery Character Editory Editor) (CCEE) WIP](https://www.nexusmods.com/baldursgate3/mods/17123).
- Full transition to [KAVT](https://www.nexusmods.com/baldursgate3/mods/16325) and virtual textures. We lost some cool Origin customisation in the process, mainly [Shart's concept art tattoos](https://www.nexusmods.com/baldursgate3/mods/8115). But less graphical issues and new features such as glowing stuff is cool and worth it. Will see what can be done about Shart's tattoos in the future, because I'll definitely miss them.
- Early game onboarding should be improved by providing 2 Injury Kits to each character and reducing the global application % chance by 20% for [Grit and Glory - Injuries Exhaustion and Madness - MCM](https://www.nexusmods.com/baldursgate3/mods/14863)!
